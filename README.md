# mafaq318.github.io

My personal site: C++, embedded Linux, automotive software, and applied ML research.

Plain HTML and CSS, hosted on GitHub Pages. No JavaScript, no build step.

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080.

The page is in `index.html`, styles in `styles.css`, and the CV at `docs/AFAQ_MOHAMMAD_CV.pdf`. The type (EB Garamond) matches the CV, so the site and the PDF read as one document.
