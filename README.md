# mafaq318.github.io

Personal profile site for Mohammad Afaq — Software Engineer / Design Lead (embedded & automotive).

Retro CRT / terminal aesthetic with dynamic visitor animations.

Live site: [https://mafaq318.github.io](https://mafaq318.github.io)

## Local preview

No build step. From the repo root:

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## Assets

- Portrait: [`assets/portrait.jpg`](assets/portrait.jpg) (currently your GitHub avatar)
- CV: [`docs/AFAQ_MOHAMMAD_CV.pdf`](docs/AFAQ_MOHAMMAD_CV.pdf)

To use a different photo, replace `assets/portrait.jpg` (square crop works best).

## GitHub Pages

This is a user site (`username.github.io`). Publish from the **root** of the default branch:

1. Push site files including `assets/` and `docs/`
2. GitHub → Settings → Pages → Source: Deploy from a branch → branch root
3. Site will be available at `https://mafaq318.github.io`
